# Políticas da loja — rascunhos

Textos-base para colar no admin da Shopify em **Configurações > Políticas**. A Shopify publica cada uma
em `/policies/<nome>` usando o layout do tema, e o rodapé lista os links automaticamente.

| Arquivo | Campo no admin | URL gerada |
| --- | --- | --- |
| `privacy-policy.md` | Política de privacidade | `/policies/privacy-policy` |
| `refund-policy.md` | Política de reembolso (trocas e devoluções) | `/policies/refund-policy` |
| `shipping-policy.md` | Política de frete | `/policies/shipping-policy` |
| `terms-of-service.md` | Termos de serviço | `/policies/terms-of-service` |
| `contact-information.md` | Informações de contato | `/policies/contact-information` |

Substitua os campos entre colchetes ([RAZÃO SOCIAL], [CNPJ]…) e **revise com um responsável jurídico**:
são modelos genéricos, não aconselhamento legal. As regras citadas (CDC art. 49, LGPD) valem para lojas
brasileiras; prazos e valores devem refletir a operação real.
